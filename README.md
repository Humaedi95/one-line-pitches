A single sentence that would convince a friend who has never coded to let an AI agent build their first app idea on [make.fun](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3). That sentence is the whole entry: no code, no explanation.

## The sentence

> That app idea you keep mentioning? Hand it to an AI agent on make.fun — it builds a first version while you watch, you keep the final say, and you finally find out if it is as good as it sounds in your head.

**207 characters** (limit: 240).

## How it runs

```sh
node main.ts
```

`main.ts` checks the sentence is 1–240 characters, then writes it exactly — no trailing newline — to `/output/entry.txt`.
